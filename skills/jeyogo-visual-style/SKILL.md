# JEYOGO 视觉风格

品牌方于 2026-11-27 确认：2L 过滤系统与 Mini 过滤吸管 V9 的视觉语言是 JEYOGO 后续默认风格。延续风格，同时服从用户本次的具体要求；不要把某个产品的图片数量、参数或配件直接套用到其他产品。

## 视觉方向

真实户外、简洁克制、产品清晰、自然明亮、有秩序的留白。以实拍使用场景和清楚的功能说明建立质感。Smartwool、Katadyn、DexShell 是早期方向参考，后续以 JEYOGO 已确认作品为基准，不复制其他品牌的设计或标识。

避免：杂乱拼贴、过多装饰线框、厚重暗绿、脏灰滤镜、夸张饱和度、每屏都一样的版式，以及为填空而添加的无意义文案。

深绿用于首屏、关键场景或少量强调区域。浅底承担大多数说明模块。无需为了统一而把每屏都做成绿底；避免绿底压暗整套页面。

## 字体和信息层级

- 英文默认 Montserrat，常规 400、半粗 600。使用品牌原始 Logo 文件，不以普通文字或生成图重画 Logo。
- 每种画布通常约三个字号层级，避免随意增加大小和粗细。重要数字可有一次明确的放大强调。
- 已确认的起点：电脑端 A+ 标题 52px、次级 28px、正文 22px；手机端标题 29px、次级 22px、正文 16px；1200 方形功能图标题 64px、次级 34px、正文 26px。根据真实文字长度调整，不机械锁死。
- 标题简短，正文说明清楚。按语义换行，避免半句话与下一句挤在一起、孤立词、用空格缩进第二行。
- 三步骤优先用短标题配简短说明，例如 Remove / Refit / Backwash，保持标题和说明基线一致。
- 成品在目标尺寸下检查可读性，手机端独立排版，不能把电脑端整体缩小。

## 照片、色彩与产品真实性

- 优先原始实拍照片、清晰视频帧；先找源文件和既有制作脚本。允许裁切、轻微提亮、温和去色偏，使产品成为视觉主体。
- 户外背景保持自然，不默认抠出人物和产品。横幅可用自然横向裁切，不用左右竖色条填补画面。
- 肤色以自然为准。偏红只轻微减红，偏黄只轻微调整；避免来回大幅染色。微暖可以，不能泛橙、泛粉或灰白。
- 对比相邻屏统一明暗和色温。阴影可稍提亮，保留层次；浅色瓶身不曝白，黑色滤芯部件仍有细节。
- 用户明确要求移除干扰物时，只处理相应局部。保留真实产品外形、接口、比例、印字和材质；检查 JEYOGO 与 TECH MEETS WILD，不能接受生成工具改错小字或改造结构。
- 抠图边缘不能悬空：手腕、前臂自然从画框边缘进入。白底产品素材先检查现有透明边缘和摆放方式，避免不必要的重新抠图。
- 警惕非售卖配件造成误解。Mini 便携展示优先只手持滤芯的画面，避免水袋、整套装备占据主要视觉；必要的场景附件标清 not included。
- 不把生成修补说成像素不变的原片。保留原图与制作记录。

## 布局与整套节奏

- 每屏一个主要结论，配图直接支撑结论。减少重复解释，不堆功能。
- 可交替使用：深绿文字区配大场景、浅底数据与报告、双使用模式、全宽实拍配下方文字、三步骤、简洁尺寸展示、套装清单。
- 相邻屏避免机械重复；但相同信息层级、边距、字体和底色要一致。
- 桌面参考边距 64px，手机参考 24px。等宽栏目、统一间距、标题基线和照片边框对齐。
- 同时检查图框对齐和框内主体的视觉对齐。不能为了上沿齐平把主体贴到顶边；上下留白要平衡。
- 产品图保留正确比例，不拉伸，不为了放大而切掉关键接口。
- 全宽场景裁切时，保留足以理解使用方式的产品、手部及相关端点。
- 结尾用轻量便携、收纳或配件信息自然收束。屏数按产品实际内容决定，不强制八屏。

## 文案和产品边界

- 美国站图内使用简洁自然的英文。
- 延长管称 Extension tube，不写 Silicone tube。不要把直接饮用文案放进只讲 28mm 瓶口连接的屏幕；每种使用方式说明准确。
- 明确套装与单件：per filter / each、配件数量、哪些不包含。Mini 的单件重量不能与 2L 套装重量混用。
- 过滤精度、效率、流速、寿命和报告编号必须从当前产品资料核对。不要把旧示例中的数字当作整个品牌通用参数。
- 报告节选保留原始内容，不改检测结果；保留测试条件、适用限制和必要的性能差异说明。
- 不以视觉简洁为理由删除关键使用限制。手机端可用完整短句压缩重复内容。

## 执行与交付

1. 检查当前 SKU 的旧版、原图、视频、参数和已有过程文件。使用确认过的版本，不从废弃草稿继续。
2. 用户已明确不需询问时，合理独立完成；用户要求逐屏讨论时，按其节奏出图。
3. 已要求保留的白底首图原样复制，必要时比对文件哈希。这个要求来自具体任务，不意味着任何新 SKU 都有两张白底图。
4. 保存制作源文件、可编辑文字/布局和素材来源；新版本单独存放，原始资料不覆盖。
5. 通常交付一个大文件夹，内含三个小文件夹：
   - 主图：1200×1200
   - 电脑端A+：1464×600
   - 手机端A+：600×450
   用户指定其他尺寸时以其要求为准。交付文件夹放成品，脚本、草稿和预览放旁边的工作目录。
6. 核对文字越界、断行、画面裁切、配件数量、标识、尺寸和三端对应关系。整套拼成长图看色温、亮度、重复版式和阅读节奏。
7. 展示可查看的总览和实际保存位置；说明改动，不把未确认稿称为用户已确认稿。

## 已确认作品定位

基准是 2026-11 的 JYWF2605（2L 系统）与 JYWF2605RP（Mini）V9 完整交付。若本机资料可用，先检查对应 SKU 的 V9 完整交付文件夹及工作文件；不要因为本文件提到这些 SKU 就把其私有原图上传到 GitHub。

GitHub 规范用于版本管理，本地安装用于技能调用。不要宣称仅上传仓库就会自动安装到其他设备，也不要承诺其他聊天一定已加载此技能。今后用户更新品牌规范时，记录具体规则变化并同步已授权的位置。
